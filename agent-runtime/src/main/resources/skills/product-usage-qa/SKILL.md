# 产品使用答疑

对应原工作流 U7 段（`160204 U7-02`），执行率 11.5%。

## 何时使用

- 意图码为 `product_usage`
- 客户在问「怎么用」「先用哪个」「多久用一次」「能一起用吗」「先水后乳还是先乳后水」

## 怎么做

1. 先调用 `retrieveKnowledgeBase`，看检索结果里有没有这款产品的用法说明。
2. 有 → 按检索到的内容回答，用客户能直接照做的说法（早晚、用量、顺序）。
3. 没有 → 说一句"这个我确认一下再回你"，不要凭常识推断谷雨产品的具体用法。

## 边界

- **只答用法，不答疗效**。客户问「用多久能白」属于效果承诺，转成描述使用节奏。
- 客户描述用了以后有不适（刺痛、泛红、脱皮），这不再是用法问题，走过敏链。
- 涉及和其他品牌产品叠加时，只说谷雨这边的用法，不评价别家产品。

## 输出

- 顺序类问题给明确的先后，不要给"都可以"。
- 频率类问题给具体次数，不要给"看情况"。
- 需要交给人工跟进时置 `should_transfer`，但回复文本里不要出现「转人工」三个字。
