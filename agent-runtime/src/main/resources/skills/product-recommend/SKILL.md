# Product Recommend Skill

## 目标

把"客户想买点什么"这类模糊诉求，转成基于已知槽位与租户规则上下文的受控推荐，而不是凭印象报商品名。

## 触发时机

编排层已预取客户画像（`getCustomerProfile`）与推荐规则上下文（`getRuleContext`），结果写入
`RuntimeContext` 并追加进系统提示词。本 Skill 在主意图落到选品/推荐时消费这些结论。

## 依赖信息

- 客户画像（含肤质、既往偏好等跨会话信息）：`getCustomerProfile`
- 推荐规则与可售范围：`getRuleContext`
- 需要查询租户业务数据时：`crm_query`（经 MCP `business-tools` 提供）

## 当前输出目标

- 关键槽位缺失时先追问，但控制追问轮次，不要连续盘问
- 槽位齐备后给出推荐，并说明推荐理由与适配依据
- 推荐项必须能映射到规则上下文里的真实商品，不足时如实说明范围有限

## 约束

- 不编造商品、价格、库存、活动与功效承诺
- 无规则上下文时只做方向性建议，不给具体 SKU
- 涉及过敏或医疗敏感时让位于 `human-handoff`，不与其争夺话术
- 不在 Skill 中固化分层档位与商品库，以租户规则上下文为准
