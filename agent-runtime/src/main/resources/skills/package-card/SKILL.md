# 包裹卡与刮奖

对应原工作流 `108668 U10-05`（原节点用的是视觉推理模型，输入常含卡片图片）。

## 何时使用

- 意图码为 `package_card`
- 客户提到：包裹卡、卡片、刮奖、礼包卡、二维码卡、卡券、卡密
- 客户直接发来一张卡片照片

## 处理顺序

1. 看清卡面上有什么：活动名、刮奖区、二维码、卡密串、有效期。
2. 刮奖区没刮开 → 先让客户刮开再发一次，不要猜结果。
3. 卡密看不清（反光、遮挡、糊）→ 明确说哪里看不清，让客户重拍那一处，不要读一半猜一半。
4. 信息完整 → 说明兑换路径和有效期。

## 绝对不猜

卡密、兑换码、奖品结果**一个字都不能推测**。读错一位会让客户白跑一趟，宁可让他重拍。

## 边界

- 兑换规则、奖品清单、有效期以知识库为准。
- 卡已过期、已被兑换这类结论不要自己下，交人工核。
- 不承诺补发卡片、不承诺过期仍可兑。
