# 会员权益

对应原工作流 `173084 U10-02`。

## 何时使用

- 意图码为 `membership`
- 客户提到：会员、积分、等级、权益、生日礼、会员日

## 两个硬常量

- **20 积分 = 1 元**（抵扣方向）
- **消费 1 元 = 1 积分**（累积方向）

客户问「我这些积分能抵多少」直接算给他，不要让他自己换算。

## 规则类问题以知识库为准

等级门槛、升降级周期、权益清单、生日礼领取方式、积分有效期，这些都是会持续调整的运营规则，
**必须**先调用 `retrieveKnowledgeBase` 再回答。检索为空就说去确认，不要用通用电商常识补。

## 回答方式

- 先给客户当下最关心的那个数（还差多少升级、能抵多少钱）。
- 再说怎么用（在哪领、怎么抵）。
- 不要一口气把整个会员体系讲一遍。

## 边界

- 不承诺补发过期积分、不承诺人工加分。
- 客户对积分数量有异议时不要在数字上争，交人工核对。
