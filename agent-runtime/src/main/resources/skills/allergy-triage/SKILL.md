# 过敏与质量分诊

对应原工作流 U9 段（`145957 U9-01` → `130100 U9-05`）。这是**风险最高**的一条链，
优先级仅次于转人工（priority 2）。

## 何时使用

必须**同时**满足两个条件：

1. 出现不适词：过敏、刺痛、红肿、灼热、发痒、泛红、脱皮、不适、烂脸
2. 出现使用痕迹：用了、用完、使用后、涂了、擦了、上脸、买的、这款

只问「你们家产品会过敏吗」属于咨询，**不走这条链**，走推荐或日常。

## 五个槽位

一次只问一个，问完为止：

1. `product` — 用的是哪一款
2. `symptom` — 具体什么反应
3. `onsetTime` — 用了多久出现的
4. `bodyPart` — 出现在哪个部位
5. `currentState` — 现在是加重、稳定还是缓解

## 静默规则（反直觉，务必遵守）

当五个槽位**全部收集完成**时，本轮 `reply_text` 输出**空字符串**，不要生成任何客户可见文本。
收集完成意味着控制权交给评估段，此时多说一句话会造成重复回复。

这条规则只在这条链成立，不要外推到别的 Skill。

## 严重度与转人工

`severityLevel` 由规则判定，不由你判：

- `severe` → 强制交人工，`riskLevel=high`。你的回复只需安抚 + 告知有人会跟上，**不要给任何处理建议**。
- 非 severe → 给基础应对（停用该产品、清水冲洗、观察），并明确说如果加重要及时就医。

## 绝对不做

- **不给医疗建议**，不推荐任何药物、药膏、剂量。
- 不判断这是不是过敏，不下诊断结论。
- 不说「正常的」「适应期」「排毒」「爆痘期」这类把不适合理化的说法。
- 不承诺赔付、不承诺一定给退。

## 输出

这条链的回复**禁止**输出分隔协议标记，必须是单段文本。
（原工作流中过敏链与售后链在这一点上相反，不要串用。）
