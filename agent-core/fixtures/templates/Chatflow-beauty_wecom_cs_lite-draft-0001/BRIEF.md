# 美妆企微轻量接待 · 知识答复与转人工（验证用）

> 这不是可交付资产，只用于验证 P2 的「2+ 候选」分支。
> 章节结构与真实 BRIEF 一致，供 PreviewService 抽取轮廓时有料可取。

## 1. 一句话定位

企微上先答疑、答不上来就转人工的轻量接待助手，不做推品与售后挽留。

## 2. 适用场景

- 只想先把常见问题接住，暂时不上推荐与营销
- 知识库内容已整理好，人工客服在线能兜底
- 单一渠道（企微）试点，先看接待量再决定要不要扩能力

## 3. 不适用场景

- 需要按肤质/预算分层推品
- 需要过敏问诊、退换挽留、任务恢复这类专项流程
- 需要跨渠道统一会话

## 4. 触发与主路径

1. 客户在企微发消息，进入会话
2. 判断这句话是在问什么（问题咨询 / 找人工 / 其他）
3. 是问题咨询就去知识库检索，命中则按口径答复
4. 检索不到，或客户明确要人工，就转给值班客服并附上会话摘要
5. 超出接待范围的话题礼貌收住，不硬答

## 5. 关键能力

- 意图识别：只区分三类，规则简单可控
- 知识答复：答案必须来自知识库，不允许自由发挥
- 转人工：带摘要转接，客服不用回头翻记录

## 6. 依赖前提

- 企微会话通道已开通
- 知识库已录入并指定生效范围

## 7. 开通前必填

| 参数 | 说明 |
| --- | --- |
| 机器人/租户标识 | 绑定到哪个企微机器人 |
| 知识库内容 | 至少两类，各 3–5 条 |
| 转人工对接 | 转给谁、夜间怎么办 |

## 8. 与近邻模板差异

比同场景的完整版少了推品分层、过敏问诊、退换挽留、任务恢复；换来的是配置项少、
上线快。要做销售转化就别选它。

## 9. 成功判据

- 常见问题的答复口径与知识库一致，不出现编造内容
- 答不上来的会话都完成了转人工，没有沉默挂断
- 转人工时客服能直接看到客户问了什么

## 10. 典型说法（可作检索语料）

- 这个怎么用
- 能不能退
- 我要找人工
- 有客服吗
